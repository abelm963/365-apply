# 365-apply

The public application page for 365 Financial Services, served by GitHub Pages at https://apply.vividmark.co.za.

It holds only this page. Applications and documents go straight from the visitor's browser to a private Supabase inbox using its publishable key, which can only add, never read. Source and tests live in the private repo abelm963/365-loan-desk (`intake/apply.html`, `tests/intake.e2e.js`). Never put customer data here.
